# Scratch
This is my space in which I will put all the different projects I built using Scratch.


## Projects

### TJ
A simple game I built using Scratch. Your objective is to collect as many cheese puffs as you can, while running from your final boss "a hungry cat". In order to do that you need to use your mouse skills. 

How to play: download TJ.sb3, go to scratch.mit.edu, click Create, then File, then Load from your computer.
